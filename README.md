# 研究室ホームページ

研究室の研究内容、ゼミ、メンバー、研究室の日常を紹介するWebサイトです。

## 開発ドキュメント
- `docs/requirements.md`：サイト全体の目的・掲載内容
- `docs/architecture-strategy.md`：ファイル構成・分業方法・共通ルール
- `docs/routing.md`：ページ一覧とURL設計
- `docs/page-specifications.md`：担当ページごとの制作仕様
- `docs/ai-development-instructions.md`：AIにコード作成を依頼するときの共通指示

## 開発方針
- GitHubリポジトリは1つに統一し、ページごとにファイルを分けます。
- 各担当者は自分のブランチで作業し、Pull Requestで`main`へ提出します。
- `main`への直接pushは禁止です。
- 共通ヘッダー、フッター、ナビゲーション、全体デザインはリーダーが管理します。
- 担当者は自分の担当範囲以外のファイルを原則変更しません。

## 技術
試作版に合わせてHTML / CSS / JavaScriptを基本とします。フレームワークや外部ライブラリを追加する場合は、事前にリーダーと相談してください。

## 開発の流れ
1. `main`を最新にする
2. Issueで担当範囲を確認する
3. `feature/担当ページ名`形式のブランチを作成する
4. AIに共通指示書と担当ページ仕様を渡して実装する
5. ブラウザで表示・動作を確認する
6. Pull Requestを作成する
7. リーダーがレビュー・統合する
