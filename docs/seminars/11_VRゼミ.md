# VRゼミ 設計書

**担当：A（リーダー）**

## 目的
VRに関するゼミの内容を伝える。。研究室に詳しくない閲覧者にも、学ぶ内容と活動の雰囲気が伝わるようにする。

## 共通構成
1. **ゼミの概要**：何を学ぶ・扱うゼミかを短く説明する。
2. **目的とテーマ**：実際に扱っているテーマを確認して紹介する。
3. **活動の進め方**：発表、実験、議論など、確認できた活動だけを書く。
4. **具体例**：実際に取り上げた内容・研究例・成果を分かりやすく紹介する。
5. **写真・動画**：掲載許可済みの活動素材を使用する。
6. **関連リンク**：研究室紹介、メンバー、論文・研究業績など必要なページへつなぐ。

## 素材・入力項目
- 正式なゼミ名：
- 担当者・参加者（公開可能な範囲）：
- ゼミの目的：
- 主なテーマ：
- 活動の頻度・方法：
- 紹介する具体例：
- 写真・動画のファイル：
- 未確認事項：

## デザイン・実装
- 他のゼミと見出し順序・カード・写真表示を統一する。
- A（リーダー）が管理する共通CSS/JSを再利用する。
- 技術用語には初学者向けの説明を付ける。
- 写真・文章は後から差し替えやすくする。
- ゼミ一覧とのリンクを確認する。

- [ ] スマートフォンでも読みやすい
- [ ] 関連ページへのリンクが動作する
