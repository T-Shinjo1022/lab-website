# 研究室ホームページ 制作企画書

## 1. 制作目的

研究室の研究内容、学生の活動、研究室の雰囲気を紹介するホームページを制作する。

研究内容を専門外の人にも分かりやすく伝えるとともに、研究室への配属を考えている学生が、研究内容や学生生活をイメージできるサイトを目指す。

英語版の制作も検討する。

## 2. ページ構成案

### 2.1 HOME

- 研究室の概要
- 研究室を象徴する画像
- 研究室紹介へのリンク
- 研究内容へのリンク
- メンバー・ゼミ・イベント紹介へのリンク

### 2.2 研究室紹介

- 研究室の目標・研究方針
  - 感性デザインとの関係を整理し、説明を更新する
- 研究設備
  - PCなどの設備を紹介する
- インタビュー風動画
  - 教員や学生の話を通して研究室の雰囲気を伝える
- 錯覚の紹介
  - 錯覚を体験できる画像などを掲載する
- 身近な疑問から研究内容への導入
  - 現象や疑問を紹介し、研究テーマにつなげる

### 2.3 メンバー紹介

- 教員・学生の人数
- 学年ごとのメンバー
- 卒業研究などの研究テーマ
- 研究テーマの簡単な説明

※写真や個人情報の掲載については本人の同意を得る。

### 2.4 ゼミ紹介

#### 普段のゼミ

- 週3回のゼミ
- 対面を基本とし、オンライン参加も可能
- ゼミ中の雰囲気が伝わる写真
- お菓子を食べている様子などの日常風景
- 実験・発表の様子

#### 学年・研究テーマごとの紹介

- デザインに関する研究
  - 3つの檜皮の写真を用いた比較・評価の紹介
- VRに関する研究
  - 拡大率関数など
- モーションゼミ
  - 仮現運動
  - 骨格推定
- モーションシャープニング
  - 研究内容の説明
  - 動画による紹介

※専門的な図や用語には、初めて見る人向けの簡単な説明を付ける。

### 2.5 イベント紹介

- 学会発表
  - 発表時の写真
  - 発表テーマと概要
- 山登り
  - 活動写真と紹介文
- バドミントン
  - 活動写真と紹介文
- 年間イベントマップ
  - 1年間のイベントを時系列で紹介
- 研究室の日常
  - 教員や学生の雰囲気が伝わる写真

### 2.6 配属希望者向けページ

- 研究テーマは学生の興味・関心をもとに検討できること
- 研究テーマの決め方
- 研究を進める際の支援
- 配属前によくある質問
- 研究室見学・問い合わせ方法

※実際の研究室の方針を教員に確認してから掲載する。

### 2.7 教員紹介

- 教員のプロフィール
- 研究内容
- 趣味など、人柄が伝わる情報

※独立ページにするか、研究室紹介に統合するかは要検討。

### 2.8 アクセス

- 研究室の所在地
- 建物名・部屋番号
- 大学構内での位置
- 連絡先
- 問い合わせ方法

## 3. デザイン方針（案）

- 研究内容を専門外の人にも分かりやすく伝える。
- 研究室の雰囲気が写真や動画から伝わるようにする。
- 初めて訪れた人が必要な情報を探しやすい構成にする。
- スマートフォンでも閲覧しやすくする。
- 後輩が継続して更新しやすい構造にする。

## 4. デザイン検討の進め方

1. 各メンバーが参考にしたいホームページを2つ探す。
2. 気に入った点と理由をGitHub Discussionsに投稿する。
3. 投稿された意見をもとにデザインの方向性を整理する。
4. トップページのワイヤーフレームを作成する。
5. 複数の案を比較し、採用する方向性を決める。

## 6. 制作時の方針

- 制作期間は1〜2か月を想定する。
- B4の5人で役割分担して進める。
- GitHubで意見、課題、決定事項を共有する。
- 決定した事項と未決定の事項を区別する。
- ゼミごとに進捗を確認し、必要に応じて計画を修正する。
