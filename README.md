# 研究室ホームページ制作プロジェクト

## 目的
GitHubを使った共同開発、AIを使ったコード作成と理解、ページ設計・デザインの改善を経験しながら、研究室の魅力が伝わるホームページを完成させます。

**実在する大学・研究室・教員・学生・研究業績・設備・イベントなどの情報は創作しません。** 未確定事項はプレースホルダーにします。

## 担当表
| 区分 | 担当者 | 担当範囲 |
|---|---|---|
| A | リーダー | HOME、共通ヘッダー・フッター、共通CSS/JS、統合、VRゼミ |
| B | Ujita | モーションシャープニングゼミ、研究室紹介 |
| C | Yamamoto | デザインゼミ、アクセス、進路 |
| D | Haga | モーションゼミ、イベント |
| E | Sakudou | メンバー、学生・教員の論文、配属希望者向け |

※教員の個人紹介ページは、担当表に独立した記載がないため、暫定的にEのプロフィール関連業務として扱います。最終担当はチームで確認してください。

## 使い方
1. `docs/common/共通開発ルール.md` と `docs/common/役割分担と進行管理.md` を確認する。
2. 担当する `docs/pages/` または `docs/seminars/` の設計書を読む。
3. `docs/common/ページ情報入力シート.md` をコピーして事実・文章・写真・未確認情報を整理する。
4. `docs/common/AI依頼テンプレート.md` に設計書と入力内容を添えてAIに依頼する。
5. 生成コードを理解し、表示確認と修正を行ってPull Requestを作成する。
6. リーダーが共通デザイン・リンク・競合を確認して統合する。

## 設計書一覧
- `docs/common/`：全員共通のルール、担当、入力シート、AI依頼文
- `docs/pages/`：各ページの設計書（HOME、研究室紹介、メンバー、イベント、配属希望者向け、教員紹介、アクセス、進路、論文・研究業績）
- `docs/seminars/`：VR、モーションシャープニング、デザイン、モーションのゼミ別設計書

## 完成の目安
正しい情報、分かりやすい文章、統一感のあるデザイン、PC・スマートフォンでの表示、ページ間リンク、公開許可、更新しやすいコードを確認します。
