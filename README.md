# 研究室ホームページ

大学の研究室を紹介するホームページを制作するプロジェクトです。

研究内容だけでなく、研究室の日常やゼミ、イベント、学生の雰囲気などを伝え、研究室について初めて知る人や配属を検討している学生が、長研究室について理解を深められるサイトを目指します。

## 1. 制作目的

- 研究室の研究内容を専門外の人にも分かりやすく紹介する
- 研究室の雰囲気や学生生活を伝える
- 配属を検討している学生に、研究テーマや研究室での活動について知ってもらう
- 後輩が引き継いで更新・管理できるホームページを作る
- 日本語版に加えて、英語版の制作も検討する

## 2. 主な掲載内容

| ページ | 掲載内容 |
| --- | --- |
| HOME | 研究室の概要、メインビジュアル、各ページへの案内 |
| 研究室紹介 | 研究方針、研究設備、錯覚の紹介、教員・学生へのインタビュー |
| メンバー紹介 | 教員・学生の紹介、学年、研究テーマ |
| ゼミ紹介 | ゼミの雰囲気、研究テーマ、実験や発表の様子 |
| イベント紹介 | 学会発表、山登り、バドミントンなどの活動 |
| 配属希望者向け | 研究テーマの決め方、研究室での活動、よくある質問 |
| アクセス | 研究室の所在地、連絡先、問い合わせ方法 |

※ページ構成は、制作を進めながらメンバーで相談して決定します。

## 3. 開発メンバー

- 制作メンバー：学部4年生 5名
- 制作期間：1〜2か月を想定
- 活動場所：研究室のゼミを中心に進捗を共有

全員で相談しながら制作を進め、Web開発やGitHubの使い方も実践を通して学びます。

## 4. 開発方針

- 初めて訪れた人にも分かりやすいデザインにする
- 写真や動画を活用し、研究室の雰囲気を伝える
- スマートフォンでも見やすいレイアウトにする
- 後輩が内容を更新しやすい構造にする
- 制作期間内に完成できるよう、優先順位を付けて開発する

## 5. GitHubの使い方

本プロジェクトでは、GitHubをソースコードの管理だけでなく、意見交換やタスク管理にも利用します。

| 機能 | 用途 |
| --- | --- |
| Issues | 作業内容、改善点、未解決の問題を管理する |
| Discussions | デザイン案、参考サイト、制作方針について話し合う |
| Pull Requests | コードの変更内容を確認し、レビューする |
| Commits | 変更内容を記録する |

### 基本的な開発の流れ

1. Issuesで担当する作業を確認する
2. 必要に応じてブランチを作成する
3. コードやファイルを変更する
4. Pull Requestを作成する
5. メンバーで変更内容を確認する
6. 問題がなければメインブランチに反映する

※GitHubの操作に慣れるまでは、簡単な作業から始め、少しずつ開発の流れを身に付けます。

## 6. ディレクトリ構成（案）

```text
lab-website/
├── README.md
├── docs/
│   ├── site-plan.md
│   ├── design-policy.md
│   └── meeting-notes.md
├── index.html
├── css/
├── js/
└── images/
```

| ファイル・ディレクトリ | 役割 |
| --- | --- |
| `README.md` | プロジェクトの概要や開発方針を説明する |
| `docs/site-plan.md` | サイトの目的、ページ構成、掲載内容をまとめる |
| `docs/design-policy.md` | デザインの方向性やルールをまとめる |
| `docs/meeting-notes.md` | ゼミでの議論や決定事項を記録する |
| `index.html` | ホームページのトップページ |
| `css/` | デザインやレイアウトに関するファイル |
| `js/` | 動きやインタラクションに関するファイル |
| `images/` | 掲載する画像などの素材 |

※ディレクトリ構成は、採用する技術や開発方法に合わせて変更します。

## 7. 制作の進め方

1. サイトの目的と掲載内容を整理する
2. 参考サイトを集め、デザインの方向性を決める
3. ページ構成とワイヤーフレームを作成する
4. メンバーで作業を分担する
5. ページを実装する
6. 表示や動作を確認し、修正する
7. 公開準備を行い、ホームページを公開する

各ゼミで進捗を確認し、必要に応じて計画や役割分担を見直します。

## 8. 制作上の注意

- 写真や動画に写る人には、掲載について事前に確認する
- 個人情報や連絡先の公開範囲に注意する
- 研究内容や研究室の方針について、必要に応じて教員に確認する
- 公開前に、リンク切れや表示崩れ、スマートフォンでの見え方を確認する
- パスワードやAPIキーなどの機密情報をリポジトリに登録しない
