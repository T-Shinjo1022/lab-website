# 要件定義書

## 1. プロジェクト概要
- 名称：長研究室ホームページ
- 目的：研究内容、研究室の雰囲気、学生生活を学内外の閲覧者に伝える。
- 対象：研究室への配属を検討している学生、大学関係者、研究者、一般の閲覧者。
- 制作体制：学部4年生5名
- 制作期間：1〜2か月を想定
- 言語：日本語を先行して制作し、英語版も検討する。

## 2. コンセプト
「見え方が変わると、世界が変わる。」
視覚・映像・感性デザインに関する研究を、専門外の人にも興味を持ってもらえる形で紹介する。研究内容だけでなく、ゼミやイベントなど研究室の日常も伝える。

## 3. コンテンツ要件

### HOME
研究室名、コンセプト、印象的なビジュアル、主要ページへのナビゲーション、研究テーマへの導線。

### 研究室紹介
研究目標・感性デザインとの関係、研究設備、錯視などの視覚現象、身近な疑問から研究への導入、インタビュー動画（素材がある場合）。

### メンバー
教員・学生の人数、学年ごとの紹介、卒業研究テーマと短い説明。写真・氏名・個人情報は本人の許可を得たものだけ掲載。

### ゼミ紹介
週3回程度のゼミ、基本は対面でオンライン参加も可能という説明（実際の運用を確認）、ゼミの雰囲気・実験・発表写真。ゼミごとに独立ページを用意する。
- デザイン：檜皮など3種類の写真の比較、印象・評価
- VR：拡大率関数、距離感、映像の臨場感
- モーション：仮現運動、骨格推定、モーションシャープニング動画

### イベント
学会発表、山登り、バドミントン、研究室の日常写真、年間イベントの時系列表示。

### 配属希望者向け
研究テーマの決め方・自由度（教員に確認）、紹介動画、先輩インタビュー、研究室の1週間、よくある質問、見学・問い合わせ。

### 教員紹介
教員プロフィール、研究内容、趣味など人柄が伝わる情報（本人に確認）。独立ページか研究室紹介内かは後で決定。

### アクセス
大学・キャンパス・建物・部屋番号、公式連絡先、地図またはキャンパスマップへのリンク。

## 4. 非機能要件
- PCとスマートフォンの両方で閲覧できるレスポンシブデザイン
- 分かりやすいページ間ナビゲーション
- 読みやすい文字と十分なコントラスト
- 画像の容量を必要以上に大きくしない
- リンク切れ・表示崩れをなくす
- 後輩が更新しやすいファイル構成
- 画像に代替テキスト（alt）を設定
- 動画は自動再生せず、閲覧者が再生を選べるようにする

## 5. 論文キーワード検索
初期版では、検索対象となる論文情報が整理できてから実装する。検索窓だけを置いて動作するように見せない。検索対象、データ形式、論文リンクの管理方法を決める。

## 6. 未確定事項
正式な研究紹介文、掲載写真の許可、ゼミの正式名称・説明、論文情報、動画素材、所在地・連絡先、英語版の範囲、公開先、公開後の更新担当。
