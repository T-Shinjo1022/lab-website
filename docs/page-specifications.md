# 担当ページ別 制作仕様書

担当者とリーダーで最終決定する。担当者は自分の担当仕様をAIに渡す。

## 5人の担当案
| 担当 | 役割 | 担当範囲 |
|---|---|---|
| A | リーダー | HOME、共通ヘッダー・フッター、共通CSS/JS、統合、VRゼミ |
| B | メンバー2 | 研究室紹介、メンバー |
| C | メンバー3 | デザインゼミ |
| D | メンバー4 | モーションゼミ |
| E | メンバー5 | イベント、配属希望者向け、アクセス |

ゼミ所属・得意分野・作業量に合わせて調整してよい。

## 担当B：研究室紹介・メンバー
研究目標・感性デザインとの関係、研究設備、錯視、身近な疑問から研究への導入、インタビュー動画の場所。メンバー人数、学年、卒業研究テーマ、短い説明。写真・個人情報は許可を得る。
作成：`about.html`、`members.html`、`css/about.css`、`css/members.css`、必要な画像。

## 担当C：デザインゼミ
ゼミ概要、感性デザイン、檜皮など3種類の写真比較、印象・評価、研究背景・目的・方法・結果の平易な説明、実験写真・図。
作成：`seminar/design.html`、`css/seminar/design.css`、`images/seminar/design/`。

## 担当D：VRゼミ・モーションゼミ
VR：拡大率関数、距離感、映像の臨場感、変換前後の画像・図。
モーション：仮現運動、骨格推定、モーションシャープニング、動画・連続画像。
作成：`seminar/vr.html`、`seminar/motion.html`、対応するCSSと画像。

## 担当E：イベント・配属希望者向け・アクセス
イベント：学会発表、山登り、バドミントン、研究室の日常写真、年間イベント。
配属希望者：研究テーマの決め方・自由度（教員確認）、紹介動画、先輩インタビュー、研究室の1週間、見学案内。
アクセス：大学・キャンパス・建物・部屋番号、公式連絡先、地図。
作成：`events.html`、`join.html`、`access.html`、対応CSSと画像。

## 全担当共通の完成条件
- 担当ページがブラウザで開ける
- 共通ヘッダー・フッターとデザインが統一されている
- PC・スマートフォンで表示できる
- ページ内・ページ間リンクが正しい
- 画像が表示され、altが設定されている
- 仮情報・未確定情報が明示されている
- コンソールに重大なエラーがない
- 担当外のファイルを不必要に変更していない
